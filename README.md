# 萨卡兹的无终奇语 · Sarkaz's Furnaceside Fables

灵感来自明日方舟集成战略「萨卡兹的无终奇语」的《杀戮尖塔 2》机制拓展 Mod。

为游戏加入**思绪**、**护盾**、**去伪存真**、**诡谲断章**等系统,以及 **150+ 件收藏品**与 **30+ 种思绪**。

> 本 Mod 处于持续开发中,目前面向单人模式设计。欢迎通过 Issue 反馈 Bug 与平衡性建议。

---

## 玩法介绍

### 思绪

思绪分为三种:**灵感**、**遗愿**、**构想**,各有稀有度与思维负荷两个属性。玩过集成战略一定不陌生。

| 类型 | 说明 |
| --- | --- |
| **灵感** | 进入战斗前使用,一次只能使用一个,为本场战斗提供增益。已使用的灵感显示在右上角。战斗结束后有概率掉落。 |
| **遗愿** | 效果大多与"进入下一层"相关,同时是"去伪存真"合成遗物的主要材料。 |
| **构想** | 地图资源:花费 1 个构想刷新节点,花费 2 个构想横向行动。 |

**思维负荷**:每个思绪都有负荷。持有思绪的负荷之和超过上限 / 上限的 1.5 倍时,思绪进入**混乱 / 阻滞**状态——每进入一个节点受到无法被格挡的固定伤害(1 / 2 点,不会使生命值低于 10)。

### 护盾

全局资源。作用同战斗中的格挡,但**跨战斗保留**:受到攻击时优先扣除护盾值。无法抵挡真实伤害。

### 年代之刺

战斗中有概率出现特殊敌人**年代之刺**。它不计入作战敌人数——其他敌人全部倒下战斗即告结束;若能在此之前将它击败,可获得 1 个构想。

年代之刺每回合施加 2 点**凋亡损伤**,累计 6 点后爆发:角色每回合减少 1 点能量并持续受到伤害。

### 去伪存真

在火堆(休息)节点可以进入**去伪存真**,选择两个思绪进行解读:

- 遗愿 × 遗愿 → 获得遗物,品质取决于遗愿稀有度
- 灵感 / 构想 之间 → 获得护盾
- 遗愿 × 灵感(构想) → 概率获得遗物或护盾
- 特殊遗愿**族长头冠**可与某些灵感合成更高级的灵感

### 诡谲断章

每一幕地图的后半段都藏有 1~2 个通往**诡谲断章**的入口;部分事件中也可能出现进入的机会。

进入后获得一件**负面收藏品和一件随机藏品**。探索完毕从出口离开,你会回到进入时的节点,继续原本的旅程。

### 事件

几乎所有事件都新增了一个特殊选项,可以寻求帮助:花费金币换取构想或获得遗物,也可能有神秘的效果。

## 从源码构建

环境要求:

- [.NET SDK 9.0]
- Godot 4.5(.NET 版,与《杀戮尖塔 2》所用版本一致)

```bash
git clone git@github.com:ocean-2514/sarkazs-furnaceside-fables.git
cd sarkazs-furnaceside-fables
dotnet build
```

## 敌人与遭遇

**49 种敌人**，基于“萨卡兹的无终奇语”中的作战，加了49种敌人。大部分萨卡兹敌人基于**移速/位置**系统：每回合末向终点（蓝门）移动，到达后逃离并对玩家造成伤害。

**25 个波次制遭遇**（普通/精英），有些遭遇有多个波次：需要逐波击败敌人才可结束战斗。

## 项目结构

```
src/
├── Model/            # 游戏内容模型
│   ├── Thoughts/     #   思绪(灵感 Inspirers / 遗愿 Lingers / 构想 Plans)
│   ├── Relics/       #   收藏品
│   ├── Powers/       #   能力(Power)
│   ├── Events/       #   事件(含诡谲断章出入口、事件通用选项)
│   └── Acts/         #   诡谲断章支线层
├── Patches/          # Harmony 补丁(注入原版流程)
├── Hooks/            # Mod 自定义钩子(SarkazHook)
├── Entities/         # 运行时实体(思绪解读器等)
├── Runs/             # 局内管理器(思绪/护盾/断章状态)
├── Saves/            # 侧存档与支线地图书签(MapDetour)
├── Map/              # 诡谲断章地图生成
├── Commands/         # 命令封装(ThoughtCmd 等)
├── Rewards/          # 自定义奖励类型
└── Helper/           # 工具类
SarkazsFurnacesideFables/
└── localization/     # 本地化文本(简体中文)
```

## 技术要点

- 基于 [HarmonyLib](https://github.com/pardeike/Harmony) 对原版逻辑打补丁,内容模型通过游戏的 `ModelDb` 自动注册
- 思绪/护盾等 Mod 数据走独立侧存档,与原版存档并存、随 run 同步落盘
- 诡谲断章通过动态追加 Act + 返回书签实现"支线地图、原路返回",不影响原版终局判定
