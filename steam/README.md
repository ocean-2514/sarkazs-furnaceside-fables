基于明日方舟集成战略：萨卡兹的无终奇语，加入思绪机制。思绪分为三种：灵感、遗愿、构想。

思绪有稀有度和负荷两个属性。相信玩过集成战略的都不陌生。

护盾

添加了护盾机制。护盾作用同战斗中的格挡，但可以全局保留，可用于吸收伤害。当你要收到攻击时，优先扣除护盾值。无法阻挡真伤（不可被格挡的伤害）

灵感

灵感可在进入战斗前使用，一次只能使用一个灵感，使用后可以为战斗提供增益。







使用了的灵感会显示在右上角。





灵感的获取

战斗结束后有概率掉落灵感。后面还会做相关遗物。

 构想

构想可用于刷新节点和选择路线，花费一构想可以刷新节点，花费两构想可以横向行动。







构想的获取

在战斗中，有概率出现敌人“年代之刺”，击败后可获得一构想。年代之刺本身不算做作战的敌人数，其他敌人被击败后会结束战斗，此时若未击败年代之刺则不会获得构想。





年代之刺

年代之刺每回合会给予2点凋亡损伤，达到6点后进入凋亡损伤爆发状态。此时角色每回合减少1点能量并受到伤害。





遗愿

遗愿主要用于在“去伪存真”中合成遗物。具体可见下面的“去伪存真”一节。

不同的遗愿有不同的效果，主要与“进入下一层（幕）”有关。





去伪存真

在火堆（休息）节点可以进入“去伪存真”。



在“去伪存真”中，可以选择两个思绪进行解读。具体来说，两个遗愿解读可以获得遗物，获得的遗物质量与参与解读的遗愿稀有度有关。灵感或构想之间的解读均得到护盾。遗愿与灵感（构想）之间的解读概率得到遗物或护盾。











“族长头冠”这一特殊的遗愿可与某些灵感合成更高级的灵感。





思维负荷

每个思绪有思维负荷。玩家有思维负荷上限，当你拥有的思绪的负荷之和超过这个上限/上限的1.5倍时，思绪会进入 混乱/阻滞 状态。在这些状态下，每进入一个节点都会受到无法被格挡的固定值伤害。
